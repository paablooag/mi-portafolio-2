# Branding Digital: Tu Identidad Online

El 75% de usuarios juzga credibilidad por diseño. Un branding consistente aumenta reconocimiento de marca un 80%.

## Elementos Esenciales

```javascript
const elementosBranding = {
  logo: "Versiones primary, secondary, icon",
  colores: "Paleta 3-5 colores definidos",
  tipografia: "2-3 fuentes máximo",
  imagery: "Estilo fotográfico consistente",
  voice: "Tono de comunicación definido",
  elementos: "Iconos, ilustraciones, patterns"
}
```

## Paleta de Colores

```css
:root {
  /* Color primario - Identidad */
  --primary: #3b82f6;
  --primary-dark: #2563eb;
  --primary-light: #60a5fa;
  
  /* Color secundario - Acentos */
  --secondary: #10b981;
  
  /* Neutrales - Texto y fondos */
  --gray-900: #111827;
  --gray-700: #374151;
  --gray-500: #6b7280;
  --gray-100: #f3f4f6;
  
  /* Estados */
  --success: #10b981;
  --warning: #f59e0b;
  --error: #ef4444;
}
```

## Tipografía

```css
/* Sistema de fuentes */
@font-face {
  font-family: 'Brand';
  src: url('/fonts/brand.woff2') format('woff2');
}

:root {
  --font-heading: 'Brand', -apple-system, sans-serif;
  --font-body: 'Inter', -apple-system, sans-serif;
}

h1, h2, h3 {
  font-family: var(--font-heading);
}

body {
  font-family: var(--font-body);
}
```

## Brand Voice

```markdown
**Ejemplo Tech Startup:**
- Tono: Profesional pero amigable
- Lenguaje: Claro, directo, sin jerga
- Personalidad: Innovador, confiable, accesible
- Evitar: Jerga excesiva, promesas vacías

**Ejemplo Marca Lujo:**
- Tono: Sofisticado, exclusivo
- Lenguaje: Elegante, preciso
- Personalidad: Aspiracional, refinado
- Evitar: Casual, coloquial
```

## Checklist Consistencia

```markdown
- [ ] Logo en todas las páginas
- [ ] Colores brand en toda la web
- [ ] Tipografías consistentes
- [ ] Estilo fotográfico unificado
- [ ] Tono de voz coherente
- [ ] Iconos mismo estilo
- [ ] Redes sociales alineadas
- [ ] Emails corporativos branded
```
