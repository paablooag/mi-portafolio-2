## Factores Que Afectan el Tiempo

```markdown
**Aceleran:**
✅ Cliente prepara contenido
✅ Decisiones rápidas
✅ Feedback claro y rápido
✅ Alcance bien definido
✅ Team disponible

**Ralentizan:**
❌ Cambios constantes de alcance
❌ Feedback lento (>3 días)
❌ Contenido no preparado
❌ Stakeholders múltiples desalineados
❌ Integraciones complejas inesperadas
```

## Cómo Reducir Tiempo

```markdown
1. **Prepara contenido ANTES**
   - Textos escritos
   - Fotos optimizadas
   - Logo y branding definido

2. **Decisiones rápidas**
   - Feedback en < 24-48h
   - Aprueba diseños rápido
   - Un tomador de decisiones

3. **Alcance claro y cerrado**
   - No cambios mid-project
   - Nuevas features = fase 2

4. **Comunicación eficiente**
   - Canal directo (Slack/WhatsApp)
   - Reuniones semanales breves
   - Expectativas claras
```
