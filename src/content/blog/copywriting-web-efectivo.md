# Copywriting Web que Convierte: Guía Práctica 2025

El 80% de visitantes solo leen el titular. Solo el 20% lee el resto. Si tu copy no captura en 5 segundos, perdiste la venta.

## Fórmulas de Copywriting Que Funcionan

### AIDA (Atención, Interés, Deseo, Acción)

```markdown
**Ejemplo: Landing Page Desarrollador Web**

**Atención:**
"Tu Web Está Perdiendo 10.000€ Cada Mes Por Ser Lenta"

**Interés:**
"El 53% de usuarios abandonan webs que tardan más de 3 segundos. 
Si tu web carga en 5 segundos, estás perdiendo la mitad de tus clientes potenciales."

**Deseo:**
"Imagina una web que carga en < 1 segundo, aparece primera en Google, 
y convierte el triple de visitantes en clientes. Eso es lo que creamos."

**Acción:**
"Solicita auditoría gratuita → descubre cuánto dinero estás perdiendo"
```

### PAS (Problema, Agitación, Solución)

```markdown
**Problema:**
"¿Tu web tiene más de 3 años y se nota?"

**Agitación:**
"Mientras tu competencia tiene webs modernas que cargan al instante, 
la tuya parece de 2015, tarda 8 segundos en cargar, y pierde clientes cada día. 
Google te está penalizando en rankings. Tu tasa de rebote es del 75%. 
Cada día que pasa, pierdes más ventas."

**Solución:**
"Rediseñamos tu web completamente en 30 días. 
Performance extremo + diseño moderno + SEO incluido. 
Garantizamos PageSpeed 90+ o trabajamos gratis hasta lograrlo."
```

### BAB (Before, After, Bridge)

```markdown
**Before:**
"Recibías 5 consultas al mes por tu web"

**After:**
"Imagina recibir 50 consultas cualificadas cada mes.
Tu agenda llena sin hacer llamadas frías.
Clientes que llegan pre-vendidos porque confiaron en tu web profesional."

**Bridge:**
"Así es como lo hacemos: Web optimizada para conversión + SEO local + 
formularios estratégicos = 10x más leads en 90 días."
```

## Objeciones Comunes (Y Cómo Superarlas)

### "Es muy caro"

```markdown
## ❌ Defensa

"No, nuestros precios son muy competitivos."

## ✅ Reframe

"Entiendo tu preocupación. Déjame mostrarte por qué no es un gasto, 
es una inversión:

Si tu negocio genera 50.000€/año y aumentamos tus conversiones un 40% 
(conservador según nuestros casos), son 20.000€ adicionales al año.

La inversión de 5.000€ se recupera en 3 meses. Los siguientes 9 meses 
(y años) son ganancia pura.

La pregunta real es: ¿puedes permitirte NO invertir?"
```

### "Lo voy a pensar"

```markdown
## ❌ Aceptar derrota

"Vale, cuando decidas me avisas."

## ✅ Urgencia + Escasez

"Por supuesto, es una decisión importante.

Para ayudarte a decidir: tenemos una auditoría gratuita donde te muestro 
EXACTAMENTE qué está fallando en tu web actual y cuánto dinero estás perdiendo.

Solo hago 3 auditorías por semana. La próxima disponibilidad es [día específico].

¿Reservamos 30 minutos para que veas si tiene sentido para ti? 
Sin compromiso, y si decides seguir adelante, la auditoría descuenta 
del proyecto."
```

### "Necesito hablar con mi socio/pareja"

```markdown
## ✅ Facilitar

"Perfecto, es normal que sea una decisión conjunta.

¿Te envío un resumen con todo lo que hemos hablado para que se lo 
puedas enseñar? Incluye:

- Análisis de tu situación actual
- Nuestra propuesta específica
- Casos de éxito similares
- Inversión y ROI proyectado
- Garantías incluidas

Así tienen toda la información para decidir. ¿Cuándo podrían tener 
una respuesta?"
```

## Checklist Copy Efectivo

```markdown
## Cada Página ✅

- [ ] Titular captura en 5 segundos
- [ ] Beneficio claro (no características)
- [ ] Para quién es (y quién no)
- [ ] Prueba social (testimonios, números)
- [ ] Superar 3 objeciones principales
- [ ] CTA claro y repetido (cada pantalla)
- [ ] Lenguaje de tu audiencia
- [ ] Fácil de escanear (subtítulos, listas, negritas)
- [ ] Urgencia + Escasez (ético)
- [ ] Garantía clara

## Homepage Específico ✅

- [ ] Hero promesa clara
- [ ] 3-5 beneficios principales
- [ ] Cómo funciona (3-4 pasos)
- [ ] Casos de éxito / Testimonios
- [ ] CTA principal mínimo 3 veces
- [ ] FAQ responde objeciones
- [ ] Comparación (opcional)
- [ ] Garantías y confianza
```
