# Testing E2E que importa al negocio: casos reales y métricas

Las pruebas E2E deben validar lo que genera ingresos: flujo de compra, envío de formulario, alta de usuario y velocidad mínima aceptable.

## Buenas prácticas
- Prueba con datos cercanos a producción.
- Usa selectores estables y evita dependencias frágiles.
- Mide tiempos y errores por release para decidir despliegues.
