# Accesibilidad web: checklist empresarial para cumplir y convertir

La accesibilidad mejora SEO, experiencia de usuario y reputación de marca. Este checklist te ayuda a priorizar acciones de alto impacto.

## Elementos críticos
- Contrastes adecuados y tamaños de fuente legibles.
- Navegación por teclado y foco visible.
- Etiquetas y roles ARIA cuando sean necesarios.
- Alternativas textuales para imágenes y multimedia.
