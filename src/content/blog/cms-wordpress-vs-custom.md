## Cuándo Elegir WordPress

```markdown
✅ **Elige WordPress si:**
- Blog o web corporativa estándar
- Presupuesto < 5.000€
- Necesitas lanzar rápido (< 4 semanas)
- Actualizarás contenido tú mismo
- Tráfico < 50K visitas/mes
- Funcionalidades estándar (contacto, blog, portfolio)
- No requieres personalizaciones complejas
```

## Cuándo Elegir Custom

```markdown
✅ **Elige Custom si:**
- Aplicación web con lógica compleja
- Funcionalidades muy específicas
- Escalabilidad crítica (>100K visitas/mes)
- Performance extremo necesario
- Integraciones complejas con sistemas
- SaaS o marketplace
- Presupuesto > 10.000€
- Desarrollo continuo planificado
```
