## Hosting: Tipos y Cuál Necesitas

### 1. Hosting Compartido

```markdown
**¿Qué es?**
Tu web comparte servidor con 100-500 otras webs

**Precio:** 3€ - 10€/mes

**✅ Ventajas:**
- Muy económico
- Fácil de usar (cPanel)
- Mantenimiento incluido

**❌ Desventajas:**
- Rendimiento variable
- Recursos limitados
- Vecinos ruidosos afectan tu web

**Ideal para:**
- Blogs personales
- Webs pequeñas (< 5.000 visitas/mes)
- Landing pages simples

**Proveedores:**
- Webempresa (España) - 6€/mes
- Siteground (Recomendado) - 3€/mes promo
- Hostinger - 2€/mes
```

### 2. VPS (Virtual Private Server)

```markdown
**¿Qué es?**
Servidor virtual dedicado con recursos garantizados

**Precio:** 5€ - 50€/mes

**✅ Ventajas:**
- Recursos garantizados
- Root access
- Mejor rendimiento
- Escalable

**❌ Desventajas:**
- Requiere conocimientos técnicos
- Mantenimiento manual
- Más responsabilidad

**Ideal para:**
- Webs medianas (10K-100K visitas/mes)
- Aplicaciones web
- Múltiples sitios

**Proveedores:**
- Hetzner (Alemania) - 4€/mes ⭐
- DigitalOcean - 6$/mes
- Linode - 5$/mes
- Vultr - 5$/mes
```

### 3. Hosting Moderno (Jamstack)

```markdown
**¿Qué es?**
Hosting optimizado para sitios estáticos y aplicaciones modernas

**Precio:** 0€ - 20€/mes

**✅ Ventajas:**

**❌ Desventajas:**

**Ideal para:**
- Webs modernas (Astro, Next, Nuxt)
- Landing pages de alta conversión
- Portfolios

**Proveedores:**

- Edge Network global
- Analytics incluido

**Netlify** ⭐⭐⭐⭐⭐

- Split testing

**Cloudflare Pages** ⭐⭐⭐⭐⭐

- 0€/mes siempre

**Railway** ⭐⭐⭐⭐
- 5$ gratis/mes
- Deploy de backends fácil
```

```markdown
**✅ Ventajas:**
```

```markdown
**¿Qué es?**
Infraestructura en la nube escalable pay-as-you-go

**✅ Ventajas:**
- Escalabilidad infinita
```

## Migración de Hosting

### Proceso Paso a Paso

```markdown
## Preparación (1 día antes)

1. **Backup Completo**
   - Archivos (FTP)
   - Base de datos (phpMyAdmin)
   - Emails (si aplica)

2. **Documentar Config**
   - Versión PHP
   - Extensiones activas
   - Crons configurados
   - DNS records

## Migración (Día D)

3. **Nuevo Hosting**
   - Subir archivos
   - Importar BD
   - Configurar entorno

4. **Testing**
   - Modificar archivo hosts local
   - Verificar web funciona
   - Test exhaustivo

5. **DNS Cambio**
   - Cambiar nameservers o A record
   - Esperar propagación (2-48h)
   - Mantener hosting viejo 7 días

6. **Verificación**
   - Monitorear uptime
   - Verificar emails
   - Revisar performance
```

## Performance: Lo Que Realmente Importa

### Métricas Clave

```javascript
const metricasHosting = {
  TTFB: {
    nombre: "Time To First Byte",

    aceptable: "< 600ms",

    impacto: "Velocidad percibida"
  },
  
  uptime: {
    nombre: "Disponibilidad",
    ideal: "99.99%", // 4.38 min downtime/mes
    aceptable: "99.9%", // 43.8 min downtime/mes
    malo: "< 99%",
    impacto: "Accesibilidad"
  },
  
  bandwidth: {
    nombre: "Ancho de banda",
    necesario: "traficoMensual * tamañoPagina * 1.5",

  }
}
```
