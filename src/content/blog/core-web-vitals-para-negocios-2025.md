# Core Web Vitals para negocios en 2025: lo esencial

Mejorar Core Web Vitals impacta ventas. Prioriza LCP con imágenes optimizadas y caché eficaz, reduce CLS con tamaños reservados y controla INP con menos trabajo en el hilo principal.

## Acciones rápidas
- Usa imágenes responsivas en formatos modernos (AVIF/WebP).
- Implementa `font-display: swap` y precarga la fuente principal.
- Minimiza JavaScript no crítico y usa división de código.
