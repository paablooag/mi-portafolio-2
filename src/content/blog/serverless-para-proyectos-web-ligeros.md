# Serverless para proyectos web ligeros: cuándo sí, cuándo no

Serverless reduce mantenimiento y escala bien, pero no es universal. Evalúa tiempos fríos, límites de ejecución y coste por invocación.

## Usos típicos
- Formularios, webhooks, colas y tareas programadas.
- APIs de bajo consumo y picos impredecibles.
- Procesos batch con coste predecible.
