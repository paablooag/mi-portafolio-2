# Docker para frontend: flujos eficientes y ambientes replicables

Usar Docker en frontend evita ‘works on my machine’. Define imágenes ligeras, cachés eficientes y comandos simples para el equipo.

## Recomendaciones
- Multi-stage builds y dependencias bloqueadas.
- Montaje de volúmenes y hot reload.
- CI con caché entre jobs para acelerar pipelines.
